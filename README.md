# Java E-Commerce CRUD Practice

A Java-based E-Commerce CRUD practice application developed in 2025 to explore object-oriented programming concepts, abstraction, and the fundamentals of Java web application development.

## Overview

This application provides basic product management functionality using Java, JSP, Servlets, JDBC, and MySQL. It was developed as a hands-on coding exercise to understand how different components of a Java web application work together.

## Concepts Practised

- Classes and Objects
- Object-Oriented Programming (OOP)
- Abstraction using Interfaces
- Interface Implementation
- POJO Classes
- CRUD Operations
- JDBC Connectivity
- Separation of Responsibilities

## Features

- Add new products
- Update product prices
- Delete products
- Manage product information through a web interface

## Tech Stack

- Java
- JSP
- Servlets
- JDBC
- MySQL
- Apache Tomcat
- Eclipse IDE
